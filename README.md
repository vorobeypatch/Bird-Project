# Bird-Project (BirdOSINT)

BirdOSINT — это инструмент для OSINT-разведки со встроенным самообучающимся искусственным интеллектом. Он предназначен для автоматического сбора, анализа и сопоставления информации о цифровых объектах из открытых источников.

## 🚀 О проекте

Инструмент создан для глубокого анализа профилей в социальных сетях и других платформах. В отличие от простых проверок существования аккаунта, BirdOSINT анализирует контент страницы, извлекает упоминания, комментарии, лайки, репосты, подписки и описания, формируя структурированный отчет с выводами собственного ИИ.

## ✨ Ключевые возможности

*   **🔍 Поиск по Username:** Проверка наличия профиля на 50+ платформах (соцсети, форумы, GitHub, игровые сервисы)
*   **🧠 Умная проверка:** Анализ HTML-кода страницы для подтверждения реального существования аккаунта, а не просто ответа 200
*   **📊 Анализ профиля:** Извлечение упоминаний (@username), хэштегов (#тема), описаний и метаданных
*   **🤖 Самообучающийся ИИ:** Автоматическое обнаружение новых платформ и запоминание паттернов поиска
*   **📧 Проверка Email:** SMTP-валидация и поиск утечек через сервер.
*   **🌐 IP-геолокация:** Подробная информация об IP-адресе через сервер Bird.
*   **📡 WHOIS доменов:** Данные о регистрации и DNS через Bird DNS

## 📋 Требования

*   Python 3.7 или выше
*   Операционная система: Windows, Linux, macOS
*   Интернет-соединение

## 🔧 Быстрая установка

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/vorobeypatch/Bird-Project
    cd Bird-Project
    ```

2.  **Создайте структуру папок:**
    ```bash
    mkdir -p data/images
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```
    Или вручную:
    ```bash
    pip install pillow requests dnspython
    ```

4.  **Запустите инструмент:**
    ```bash
    python Birdint.py
    ```
## 🎮 Использование

1.  **Запустите скрипт**
2.  **Дождитесь анимации приветствия**
3.  **Выберите функцию из меню:**
    *   `1` - Поиск по Username
    *   `2` - Проверка Email
    *   `3` - Информация об IP
    *   `4` - WHOIS информация о домене
    *   `0` - Выход
4.  **Введите данные для поиска**
5.  **Просмотрите результаты**
6.  **Нажмите Enter для возврата в меню**

## 🔍 Как работает ИИ

1.  **Обучение на результатах:** Запоминает успешные и неудачные проверки по каждой платформе
2.  **Автоматическое обнаружение:** Находит новые платформы в результатах поиска и добавляет их в базу
3.  **Анализ профилей:** Извлекает упоминания, хэштеги и описания для формирования полной картины
4.  **Генерация отчетов:** Создает структурированный вывод со статистикой и рекомендациями
